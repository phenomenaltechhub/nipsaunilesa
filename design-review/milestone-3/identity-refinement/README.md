The previous studies remain in their existing folder and the active M1/M2 app identity is unchanged. **No concept is final or approved for application.**

Each concept has transparent light/dark/one-colour SVG symbols, original path-based PHARMAIDEIA/NIPSA UNILESA lettering, an app-icon SVG/PNG and a simplified optical micro symbol. The nexus uses angular book wings and a molecular spine. The insignia uses an open hexagonal frame, book leaves and a bonded centre; it is not an official university seal.

Login images are illustrations, not connected authentication. Dashboard imagery is taken from the actual running app and overlaid only within the review image, never applied to source. Generic phone/icons are original unbranded geometry. Actual 16/24/32/48/64px samples are supplied; legibility still needs owner/device review and is not proven by automated dimension checks. The 16/24px optical symbols intentionally remove fine cuts/bonds, retaining the same identity.
