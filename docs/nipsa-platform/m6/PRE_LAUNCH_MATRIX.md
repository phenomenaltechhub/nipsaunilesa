# M6 pre-launch completion matrix

This supersedes the current-state columns in the historical [M5 matrix](../m5/PRE_LAUNCH_MATRIX.md). **Every approved function must be implemented, integrated, secured, tested and reviewed before the first public launch. None is assigned to post-launch.** M6 success is not full-platform completion. Unavailable source/content/infrastructure blocks the corresponding gate rather than removing scope.

Status terms: **controlled-tested** = actual isolated synthetic backend/browser behavior; **local-tested** = working independent browser tool; **integration pending** = real component still needs its authenticated/operational connection; **source/content/infra/approval-blocked** = required external input absent. No production service is inferred.
