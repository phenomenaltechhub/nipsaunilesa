# Pre-launch completion policy and milestone assignment

Owner instruction, 17 November 2026: **every approved Pharmaideia function must be implemented, integrated, secured and tested before first public launch. No approved PWA feature is assigned to post-launch.** M4 is one development increment, not launch acceptance. This matrix supersedes earlier suggestions that community/CBT could wait until after launch. Historical milestone reports describe their actual past state and remain unchanged.

| Approved function | M4 actual state | Completion milestones / required gate |

No row is silently dropped because hosting or source is unavailable. Missing hosting, verified content, editorial source, reviewer capacity or institutional policy blocks the relevant acceptance gate and therefore blocks full launch. Only an explicit later owner-approved scope change may alter approved requirements. Funding/provisioning, production/DNS, real accounts and live payments need separate authorisation.

Academic calculator candidates remain evaluation-only, pending scope/formula/policy approval; no patient-specific clinical calculator is approved. Existing public website, Navigator, gallery download-time watermark and Pages workflow remain protected throughout these milestones.
