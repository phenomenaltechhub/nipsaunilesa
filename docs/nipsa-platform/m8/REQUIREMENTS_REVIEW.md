Current polling and controlled 1,000/minute global guard are not sized for 887 simultaneous users; validate worker supervision, storage quotas/actual disk use, latency and failure/load behavior on the approved host.
5. **Normal PR access:** follow the [PR runbook](PR_READINESS.md) once authorized GitHub access is restored. Existing workflow triggers main pushes/manual dispatch, not PRs; do not claim GitHub checks/protections passed when only local commands ran.
