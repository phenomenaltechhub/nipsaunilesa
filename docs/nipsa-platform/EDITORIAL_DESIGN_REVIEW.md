Recommended navigation remains Overview, Review Queue, Content Studio, Student Ads, Gallery & Media, Resources & Opportunities, Campus Navigator, Publishing Calendar, Activity & Settings. The separate student app uses Dashboard. Public sender attribution must reference a verified entity/position while preserving the immutable authenticated actor. Multiple users may hold the same role. Browser approval/status flags cannot publish or impersonate a sender.

Gallery operations must preserve the existing website-controlled **download-time Canvas watermark** and unchanged originals. Student Ads require policies/consent, disclosed package/quotation/charges, trusted server payment reconciliation, final editorial approval and expiry/renewal. Campus Navigator content must retain real source evidence and precise coordinates only for actual verified destinations. No data is invented for this proposal.
