# M7 pre-launch matrix and explicit M8 requirements

Every approved feature must be implemented, integrated, secured, tested and reviewed **before the initial public launch**. No row below is post-launch scope. M7 is a controlled increment; this matrix does not authorize production or silently remove earlier approved functions.

Status vocabulary: **L** implemented/locally tested; **C** integrated in controlled synthetic staging; **P** verified in production-like external infrastructure; **B** blocked by external requirements; **N** not implemented. No external service/host earns P in this milestone. Actual local TLS is C, not proof of a provider's HTTPS operations.
